# HR Files API Project

## Project Description
This project focuses on Python file handling, environment variables and API requests.

## Tasks Completed
- Created a virtual environment.
- Installed required Python packages.
- Read employee data using csv.DictReader.
- Converted employee data into JSON.
- Created a CSV file for employees earning above 50000.
- Used python-dotenv to load environment variables.
- Added .env to .gitignore.
- Retrieved user details using an API.
- Handled timeout, connection and HTTP errors.
- Extracted nested JSON data and saved it in users.json.

## Technologies Used
- Python
- CSV
- JSON
- Requests
- Python-dotenv
- Git and GitHub

## How to Run
1. Install packages using `pip install -r requirements.txt`.
2. Activate the virtual environment.
3. Run `python main.py`.
